scoop.md

Default: https://api.scoop.md/v1. For local development use http://localhost:8787/v1 (npm run server). Leave empty to work fully offline, with no shared library. Shared: the public sources of the page you scoop (its .md file, llms.txt files, or the page text as anyone would see it without logging in), the page URL and title, and an anonymous install ID. Only material fetched without your cookies or logins is ever shared. Votes and reports are sent with the same install ID.
